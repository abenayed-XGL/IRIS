# Third-party files served by this site

Kept here instead of loading them from Google Fonts, Font Awesome, unpkg or jsDelivr,
which are blocked or unreliable in mainland China (a blocked stylesheet leaves the page
blank until the browser gives up).

| Folder | What | Version | Source (npm) |
|---|---|---|---|
| fonts/ | Barlow, Roboto Mono (latin, woff2) | 5.1.0 | @fontsource/barlow, @fontsource/roboto-mono |
| fontawesome/ | Font Awesome Free icons (css + woff2) | 6.7.0 | @fortawesome/fontawesome-free |
| js/popper.min.js | Popper (used by tooltips) | 2.11.8 | @popperjs/core |
| js/tippy-bundle.umd.min.js | Tippy tooltips | 6.3.7 | tippy.js |
| js/mark.min.js | mark.js search highlighting | 8.11.1 | mark.js |
| css/pygments-tomorrow-night-eighties.css | code highlighting theme | | StylishThemes/Syntax-Themes |

Each folder keeps its licence file.
